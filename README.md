## 🎯 Why Studyspace?

Most study apps are noisy. Studyspace is the opposite: one quiet page with
everything you need and nothing you don't.

## ✨ Features

| | |
|---|---|
| ✅ **Smart Tasks** | Add tasks, set priority (high / medium / low), filter, and check them off |
| ⏱️ **Focus Sessions** | A built-in timer to keep you in the zone |
| 📝 **Notes & Captures** | Jot down thoughts before they disappear |
| 📅 **Coming Up** | Keep your next deadlines in sight |
| 💾 **Auto-Save** | Everything is stored in your browser, so nothing is lost on refresh |
| 📱 **Responsive** | Looks great on desktop and phone |
